Smart AI Meeting Assistant

Smart AI Meeting Assistant is an AI-powered meeting intelligence platform designed to simplify the process of recording, transcribing, and analyzing meetings.

The system processes meeting audio, converts speech into text, identifies speakers, and analyzes conversations to generate meaningful insights such as meeting summaries, key points, decisions, action items, sentiment, and meeting scores. It also provides automated meeting reports through a web-based interface.

The project is built using React, Python, FastAPI, SQLite, and modern AI/NLP technologies.
